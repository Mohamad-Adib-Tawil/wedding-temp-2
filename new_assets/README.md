# حزمة الصور والعناصر الجديدة

هذه الملفات أُنشئت لهذا المشروع من دون استخراج صور أو فيديو أو كود أو خطوط من هلاهيل. الأشخاص خياليون ومجهولو الهوية ولا يمثلون العروسين الحقيقيين. الأسماء والنصوص تُعرض في HTML فقط ولا توجد داخل الصور.

الصور العمودية والأفقية تعكس الفكرة البصرية المطلوبة: باب، قاعة، ثريّات، ستائر، ضوء ذهبي، وعريس ببدلة سوداء. أما التكوين والتفاصيل والأشخاص فهي جديدة، لذلك ليست نسخة مطابقة للصورة المرجعية.

## مطالبات التوليد

1. **عروس الغلاف:** عروس خيالية مجهولة من الخلف، فستان عاجي مطرّز وطرحة طويلة، يد قرب باب غير مرئي، إضاءة كهرمانية، خلفية شفافة حقيقية، بلا وجه ظاهر أو نص أو شعار.
2. **القاعة العمودية:** قاعة بزخارف كريستالية وستائر شامبانيا وورود بيضاء وإضاءة ذهبية؛ زوجان خياليان من الخلف في الربع السفلي، العريس ببدلة زفاف سوداء وقميص أبيض وربطة عنق سوداء، وسط داكن فارغ للنص المنفصل، بلا كتابة.
3. **ورق الدعوة:** ورق عاجي بملمس طبيعي وإطار ذهبي رقيق وزهور في الزوايا فقط، مساحة مركزية واسعة فارغة للنص العربي الخارجي، بلا كتابة.
4. **القاعة الأفقية:** تكوين أفقي أصلي بنفس لوحة القاعة الجديدة، زوجان خياليان من الخلف أسفل المنتصف، بدلة سوداء رسمية للعريس، ستائر وثريّات وورود، بلا وجوه واضحة أو نص أو شعار.
