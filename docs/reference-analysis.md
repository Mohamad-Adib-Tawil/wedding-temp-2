# تحليل مرجع «ثريّا» قبل التنفيذ

المرجع: https://halaheel.com/d/demo-thurayya — عايناه تفاعليًا على شاشة هاتف في 27 سبتمبر 2026. قدّم المالك لاحقًا أرشيف القالب وأذن بإعادة استخدام أصوله؛ تفاصيل المصدر والحقوق في `docs/asset-register.md`. أُعيد بناء منطق الدعوة في هذه الريبو بدل نسخ شيفرة النسخة التجريبية.

| الترتيب | المشهد المرصود | الانتقال والتوقيت المرصود تقريبًا |
| --- | --- | --- |
| 1 | غلاف عمودي بدرجات بني داكن: قوس باب، صورة عروس من الخلف، أسماء عربية كبيرة، وتعليمة للمس الباب. زر الموسيقى عائم أسفل الشاشة. | ثابت حتى لمسة الضيف. |
| 2 | يبدأ انفتاح الباب، يزداد الضوء خلفه وتظهر حركة انكشاف المشهد. | يبدأ فور اللمس؛ الانتقال إلى القاعة خلال نحو 2–3 ثوانٍ. |
| 3 | قاعة احتفال بستائر متناظرة، ثريّات مضيئة، ورود ولمعات دقيقة. فوقها عنوان صغير، أسماء بارزة، تاريخ، وعبارة قصيرة تظهر بالتتابع. | بعد فتح الباب، تتدرج العناصر بصريًا خلال الثواني الأولى. لم نتحقق من ميلي ثانية دقيقة لكل طبقة. |
| 4 | صفحة طويلة بلون عاجي وذهبي: تمهيد وبطاقة دعوة، ثم عد تنازلي، برنامج الحفل، المكان والخريطة، تنويهات، التقويم، RSVP، ثم كلمات مهنئين. | بالتمرير بعد المشهد الرئيسي. المحتوى التجريبي في المرجع لا يُنقل. |

الهوية المرئية المرصودة: خط عربي زخرفي للأسماء والعناوين، خط عربي مقروء للفقرات، لوحة بني داكن / عاجي / ذهبي، إضاءة ناعمة ولمعات قليلة. يوجد زر موسيقى، لكن نوع المقطوعة ومدتها ومستوى صوتها لم يمكن توثيقها سمعيًا؛ لذلك صُنعت مقطوعة أصلية قصيرة مستقلة.

## توقيت النسخة الجديدة

| الوقت من اللمس | الحدث |
| --- | --- |
| 0 ms | بدء الصوت الأصلي من تفاعل الضيف (ما لم يفعّل تقليل الحركة)، وبدء فتح الباب. |
| 0–10000 ms | تشغيل فيديو الباب المصرّح به بعد تفاعل الضيف. يفتح الباب قرب منتصف الفيديو، وتبدأ الومضة قرب 8850 ms. |
| نهاية الفيديو (نحو 10000 ms) أو 16000 ms كحد احتياطي عند تعذّر اكتماله | بدء ظهور القاعة بصورة معدّلة يظهر فيها العريس ببدلة سوداء. |
| +450 ms | ظهور العنوان. |
| +1250 ms | ظهور الأسماء. |
| +2100 ms | ظهور العبارة والدعوة للمتابعة. |
| +7800 ms | إظهار الصفحة الكاملة تلقائيًا. |

زر «تخطّي المقدمة» ينقل مباشرة إلى الصفحة، وزر «إعادة العرض» يعيد الغلاف. مع تفعيل تقليل الحركة، تظهر الصفحة فور فتح الباب بلا انتقالات أو تشغيل صوت تلقائي.

## الاختلاف المتعمد

يستخدم الباب فيديو القالب الذي قدّمه مالكه، بينما صورة القاعة والمشاركة مشتقتان من صوره بتعديل لباس العريس إلى بدلة سوداء. الأسماء قصيرة في المشهد السينمائي وكاملة في الدعوة. لا تظهر أقسام الموعد والعد والبرنامج والمكان والتقويم وRSVP حتى تُضاف بيانات حقيقية لها في الإعدادات. لا يوجد جدار تهانٍ بلا خدمة حفظ حقيقية، ولا علامة تجارية أو تهانٍ تجريبية من المرجع. تحليل التسجيل الذي أرسله المستخدم في `docs/video-reference-analysis.md`.
