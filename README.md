# دعوة زفاف محمد أديب طويل ورزان بطايحي

موقع دعوة مستقل، ثابت، عربي RTL، مستوحى من فكرة التسلسل السينمائي لقالب «ثريّا» بهوية مرئية وأصول مختلفة.

## إعداد البيانات

كل الأسماء والنصوص والموعد والوقت والمنطقة الزمنية والمكان والرابط وخطة الحفل وجهة RSVP ومسار الصوت في [`src/wedding-config.js`](src/wedding-config.js). لا تظهر أقسام الموعد والعد والتقويم إلا مع `weddingDate` و`startTime` و`timeZone` صالحة. لا يظهر المكان أو الخريطة أو برنامج الحفل أو RSVP إلا عند توفير بياناتها.

RSVP الحالي رابط واتساب مباشر فقط عند إضافة رقم صالح. لا يوجد نموذج حفظ أو جدار تهانٍ. لإضافة نموذج أو تهانٍ لاحقًا، يجب ربطهما بخدمة خلفية حقيقية.

## التشغيل

```sh
npm run build
python3 -m http.server 4173 --directory dist
```

افتح `http://localhost:4173/`. ملف `index.html` في جذر المستودع ناتج من البناء؛ تُحقن فيه وسوم المشاركة من ملف الإعدادات. عند تغيير الإعدادات شغّل `npm run build` ثم أضف `index.html` المُولّد إلى الالتزام. ينشر GitHub Pages جذر فرع `main` مباشرةً؛ لا يلزم اعتماد GitHub Actions.
