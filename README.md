# دعوة زفاف محمد أديب طويل ورزان بطايحي

موقع دعوة مستقل، ثابت، عربي RTL، يعيد تقديم التسلسل السينمائي لقالب «ثريّا» باستخدام أصول وتنسيق CSS قدّمها مالك القالب وصور معدّلة خاصة بهذه النسخة. منطق التطبيق في هذا المستودع مستقل عن شفرة JavaScript التجريبية.

أصول القالب التي قدّمها مالكه، والصور المعدّلة التي يظهر فيها العريس ببدلة سوداء، ونسخ الويب الأخف موثّقة في [`new_assets/`](new_assets/README.md). العروسان المصوّران شخصان خياليان. بعد فتح الباب تبقى القاعة أول قسم في الصفحة، ثم تظهر الآية وبطاقة الدعوة بالتمرير.

## إعداد البيانات

كل الأسماء والنصوص والموعد والوقت والمنطقة الزمنية والمكان والرابط وخطة الحفل وجهة RSVP ومسار الصوت في [`src/wedding-config.js`](src/wedding-config.js). لا تظهر أقسام الموعد والعد والتقويم إلا مع `weddingDate` و`startTime` و`timeZone` صالحة. لا يظهر المكان أو الخريطة أو برنامج الحفل أو RSVP إلا عند توفير بياناتها.

RSVP الحالي رابط واتساب مباشر فقط عند إضافة رقم صالح. لا يوجد نموذج حفظ أو جدار تهانٍ. لإضافة نموذج أو تهانٍ لاحقًا، يجب ربطهما بخدمة خلفية حقيقية.

## التشغيل

```sh
npm run build
python3 -m http.server 4173 --directory dist
```

افتح `http://localhost:4173/`. يولّد البناء ملفي `index.html` و`index.template.html` في جذر المستودع مع JavaScript مضمّن، فتعمل المعاينة أيضًا عند فتح أي منهما مباشرةً عبر `file://`. مصدر HTML القابل للتعديل هو `scripts/page.template.html`. عند تغيير الإعدادات شغّل `npm run build` ثم أضف الملفين المُولّدين إلى الالتزام. ينشر GitHub Pages جذر فرع `main` مباشرةً؛ لا يلزم اعتماد GitHub Actions.
